# ZhCode Bridge / 中文代码桥

A Chinese keyword bridge for learning real JavaScript in VS Code.

ZhCode Bridge is an open-source learning tool for Chinese-speaking programming beginners. It lets users write limited JavaScript with Chinese keywords, then translates it into standard JavaScript for real execution.

中文代码桥不是一门新的中文编程语言，而是一座桥：让中文母语初学者先用“如果、函数、返回、打印”等中文关键词理解代码结构，再逐步进入真实 JavaScript 生态。
